# PPTX: official skill and workstation overlay

1. Read [Anthropic's current PPTX instructions](https://raw.githubusercontent.com/anthropics/skills/main/skills/pptx/SKILL.md) when using this skill. The [official directory](https://github.com/anthropics/skills/tree/main/skills/pptx) contains its helper scripts and license.
2. Read [SYSTEM_OVERLAY.md](SYSTEM_OVERLAY.md) for this workstation's paths and environment differences. Apply it to environment assumptions; use upstream for presentation workflows and technical guidance. User and project instructions take precedence.
3. Run helpers from a separately installed official bundle, resolving paths against that bundle rather than this reference directory. If a new upstream workflow needs helpers your installed bundle lacks, refresh that bundle first.

This directory contains original routing and environment notes, not a copied upstream implementation. See [README.md](README.md) for setup and update behavior.
